# Diff viewer

In Focus mode, the diff panel shows the current git state of the session's folder next to the terminal.

- Three sections: unstaged, staged and branch changes.
- Refreshes every 3 seconds while the session is running, plus a manual refresh button.
- Expandable per-file sections with addition and deletion counts, and `NEW` and `DELETED` badges.
- Expand the panel to fullscreen. Press Escape to collapse.

To stage and commit from the panel, see [Git](../git/).
