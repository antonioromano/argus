# Window restore

Each window reopens where you left it:

- The session it was focused on.
- Its open side panel.
- Its group filter.

Window positions are saved continuously, so a crash or force-quit keeps them. A window that would open off-screen is pulled back onto a visible display.

Toggle this in Settings, General, Windows, Restore layout on launch.
