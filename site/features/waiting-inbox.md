# Waiting inbox

Press `Cmd+Shift+J` (also in the View menu and Find & Jump) to list every session waiting on input, longest-waiting first, with its question. The shortcut is rebindable in Settings, Keyboard.

- Up and down arrows pick a session.
- Enter jumps to it.
- A digit answers a numbered menu prompt without leaving the inbox.
- Space marks sessions, and `B` then [broadcasts](../broadcast/) input to them.

The [status bar](../status-bar/) "N waiting" count opens the inbox.
