# Git

Use commit mode in the [diff panel](../diff/) to stage and commit without leaving Argus.

- **Selective staging:** stage whole files, hunks or single lines with tri-state checkboxes.
- **Commit bar:** write a message, optionally amend (it pre-fills the last message), and commit with a click or Ctrl/Cmd+Enter.
- **Discard with undo:** discard selected changes at hunk or line level. You have 30 seconds to undo.
- **Stale diff warning:** if the diff refreshes while commit mode is active, a banner warns you before you stage outdated selections.

Worktree sessions can be finished in one step with the beta [Worktree lifecycle](../../beta/worktree-lifecycle/).
