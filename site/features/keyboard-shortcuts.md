# Keyboard shortcuts

| Key | Action |
|-----|--------|
| `Escape` | Exit diff fullscreen, then close the diff panel, exit explorer fullscreen, close the explorer panel, then exit Focus mode (in that order) |
| `Ctrl/Cmd+Enter` | Submit the commit message when the commit bar is focused |
| `Cmd+Shift+J` | Open the [waiting inbox](../waiting-inbox/) |
| `Cmd+K` | Open the command palette |

Rebind shortcuts in Settings, Keyboard.
