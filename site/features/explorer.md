# File explorer

Browse a session's project files next to its terminal.

- Tree browser scoped to the session's working directory.
- Syntax highlighting for many languages.
- Search by filename or file content.
- Edit files in place. Argus compares the file's modified time so it will not overwrite changes the agent made after you opened it.
- Markdown files render with formatting.
- Copy the full file contents with one click.
- Resizable panels; sizes persist.
- Open a real shell in the session's folder without creating a new session.
- Selected session, file and search query persist across tab switches.
