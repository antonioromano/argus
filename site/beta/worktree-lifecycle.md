# Worktree lifecycle

Finish a worktree session in one go: commit, push and open a PR. Remove the worktree once it is merged; stale worktrees get flagged.

## How to use

Right-click a worktree session, then Finish...

## Before you turn it on

- Works on worktree sessions.
- Uses `gh` if it is installed.

## Enable it

Settings, Beta features, then switch on "Worktree lifecycle".
