# Session templates

Save a set of sessions (agent, folder, optional new worktree, first prompt) and start them together into a new group.

## How to use

Settings, Launchers, Templates, or Cmd+K then "Launch template...".

## Before you turn it on

- Up to 8 sessions per template.

## Enable it

Settings, Beta features, then switch on "Session templates".
